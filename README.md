# Система рейтинга школ на Python (ООП)

Этот проект — демонстрация практических навыков разработки на Python. Программа читает данные о школах из файла формата JSON, создает на их основе объекты с использованием принципов объектно-ориентированного программирования (ООП), строит рейтинг и сохраняет готовый отчет в текстовый файл.

## 🛠️ Функционал программы:
1. **Чтение данных:** Загружает информацию о школах из файла `schools.json`.
2. **ООП и наследование:** Используется иерархия классов (`Building` -> `School` -> `Class_students`) для структурирования данных.
3. **Обработка ошибок:** Если в JSON-файле не хватает ключей, программа не падает, а пропускает битые данные (используется `try/except`).
4. **Сортировка:** Строит рейтинг школ по количеству учеников в классе (от большего к меньшему) с помощью функции `sorted()`.
5. **Экспорт отчета:** Сохраняет итоговый рейтинг в файл `rating.txt` в удобном для чтения формате.

## 📂 Структура проекта:
*   `main.py` — основной скрипт с классами и логикой.
*   `schools.json` — файл с исходными данными (пример).
*   `rating.txt` — готовый отчет, который генерируется после запуска.

## 🚀 Как запустить:
1. Убедитесь, что у вас установлен Python 3.
2. Скачайте все файлы проекта в одну папку.
3. Откройте терминал в этой папке и выполните команду:
   ```bash
   python main.py
